# topplestudio.github.io

Topple Studio's website, served by GitHub Pages at https://topplestudio.github.io

- `/` the studio and its games
- `/<game>/` a game's page, `/<game>/privacy/` its privacy policy (Topple: `/topple/privacy/`, linked from the game's Settings and both store listings)
- `/app-ads.txt` AdMob's authorised sellers file for every game (added once the AdMob account exists)
